| フェーズ | 月額コスト目安 |
|---------|-------------|

## 1. AWS Location Service

### 無料枠（フリートライアル）

アカウント作成から **3ヶ月間**、以下の枠が毎月無料で使える。

| 機能 | 無料枠（月） |
|------|------------|
| **Maps** — 地図タイル取得 | 500,000 リクエスト |
| **Maps** — 静的マップ | 5,000 リクエスト |
| **Trackers** — 位置情報書き込み | 200,000 回 |
| **Trackers** — バッチ位置情報読み取り | 10,000 回 |
| Service Resources（リソース作成等） | 10,000 回 |

> ⚠️ 2025年7月15日以降に新規登録のAWSアカウントは最大$200のフリートライアルクレジット方式に変更予定。既存アカウントは従来の3ヶ月無料枠が適用される場合があります。

### 旅行中の使用量試算（2台・3日間）

#### Tracker（位置情報の送受信）

アプリの動作：更新ボタンを押すたびに
1. 自車位置を **1回書き込み**（`BatchUpdateDevicePosition`）
2. 全車両位置を **1回読み取り**（`ListDevicePositions`）

```
想定ボタン押下回数: 50回/台/日 × 2台 × 3日 = 300回

位置情報書き込み: 300回
位置情報読み取り: 300回（1リクエストで全台取得できるため）

無料枠 200,000回 に対して 300回 → 消費率 0.15%
```

#### Maps（地図タイル）

MapLibre GL JS は地図を表示する際にタイルを自動取得する。
ズームレベルや移動量によって変わるが、1画面表示で概ね **20〜50タイル** 程度。

```
想定: 1回の更新で地図が再描画 → 30タイル × 300回 = 9,000タイル
+ 初回起動・スクロール等: 約 5,000タイル
合計: 約 14,000タイル

無料枠 500,000タイル に対して 14,000タイル → 消費率 2.8%
```

#### 旅行中の費用

| 項目 | 使用量 | 無料枠 | 超過 |
|------|--------|--------|------|
| 位置情報書き込み | ~300回 | 200,000回 | **なし** |
| 位置情報読み取り | ~300回 | 10,000回 | **なし** |
| 地図タイル | ~14,000回 | 500,000回 | **なし** |

**旅行中の AWS 費用: $0**

今回のような個人利用規模では依然として非常に安い。

> ⚠️ 正確な単価は AWS コンソールの[料金ページ](https://aws.amazon.com/location/pricing/)で確認すること。
> 料金は変更される場合があります。

| 機能 | 参考単価 |
|------|---------|
| 地図タイル取得 | 約 $0.04 / 1,000 リクエスト |
| 位置情報書き込み | 低額（ティアによって変動） |
| 位置情報読み取り | 低額（ティアによって変動） |

**旅行2〜3日間の利用を通年に換算した場合でも、月額 $1 未満が見込まれる。**

## 2. Vercel（ホスティング）

### Hobby プラン（無料）

今回採用するプランは **Hobby（完全無料）**。

| 項目 | 制限 |
|------|------|
| 月額費用 | **$0** |
| デプロイ | 無制限 |
| カスタムドメイン | 利用可（今回は不要） |
| HTTPS / SSL | 自動 |
| CDN（グローバル配信） | 含む |
| 帯域幅 | 100 GB / 月 |
| Serverless Functions 実行時間 | 100 GB-hours / 月 |
| ビルド時間 | 6,000 分 / 月 |

> ⚠️ Hobby プランは**個人・非商用プロジェクト専用**。
> 商用利用には Pro プラン（$20/月）へのアップグレードが必要。
> 今回の友人間プライベートアプリは Hobby 範囲内と考えられる。

### 旅行中の使用量試算

```
帯域幅:
  HTML/JS/CSS: 約 1 MB × 初回アクセス 10回 = 10 MB
  API レスポンス: 約 1 KB × 600回 = 600 KB
  合計: 約 11 MB

帯域幅 100 GB 無料枠に対して 0.01 GB → 消費率 0.01%
```

**Vercel 費用: $0**

## 3. Supabase（Phase 2 以降）

Phase 2 で追加予定の DB。

| プラン | 費用 | 内容 |
|--------|------|------|
| **Free** | **$0** | 500 MB DB、無制限 API コール |
| Pro | $25 / 月 | 8 GB DB、日次バックアップ |

旅行履歴の位置情報ログは1回の更新ごとに1レコード。
2台 × 数百回 = 数百件のレコードは Free プランの 500 MB に余裕で収まる。

**Phase 2 Supabase 費用: $0（Free プランで十分）**

## 5. コスト管理のポイント

### AWS 請求アラートの設定（推奨）

万が一の誤設定や想定外の利用に備えて、AWS に請求アラートを設定しておくこと。

```
AWS コンソール → Billing → Budgets → 予算を作成
  → 予算タイプ: コスト
  → 金額: $5（月）
  → アラート: 80% で通知メール送信
```

### キーの流出リスク

- **IAM アクセスキー**（サーバーサイド用）が GitHub に漏洩すると、
  不正利用で多額の請求が来るリスクがある。
- **`.env.local` を絶対に git commit しないこと**。
- 万一流出した場合は IAM コンソールで即座にキーを無効化→削除すること。
